# References

External reference material that informs the project, one markdown file per
topic. Sources can be design boards, datasheets, API docs, or articles.

## How to add one

1. Create `<topic>.md` here: summary, key facts, source link/file.
2. If the source is a file (PDF, image), drop it alongside and link it.
3. Agents without access to the source system (design boards, databases,
   automation): record an infra ask in `memory/NOW.md` →
   "For owner (infra asks)" instead of trying to fetch it yourself.
